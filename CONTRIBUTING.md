# Участие

Для исправления приложите версию Android/прошивку, версию BrowserRouter, браузер-получатель и обезличенный пример URL/правила. Не публикуйте токены из query, личную историю, keystores или пароли.

Сначала воспроизведите проблему и добавьте соразмерную проверку движка либо Android-сценария. Меняйте правило в общем движке, а не специальным исключением для конкретного браузера. Запустите проверки из docs/build-release.md. Изменение JSON требует явной версии/миграции; UI — screenshot при обычном и увеличенном шрифте.
